Web Defacement Investigation | Splunk BOTS v1

Overview

This project documents a hands-on investigation of a Web Defacement scenario using the Splunk Boss of the SOC (BOTS) Version 1 dataset.

The investigation focuses on analyzing web server logs, identifying suspicious HTTP activities, and understanding the events associated with the web defacement attack.

Tools & Technologies

- Splunk Enterprise
- Splunk BOTS v1 Dataset
- HTTP Log Analysis
- Nessus Vulnerability Scanner
- MITRE ATT&CK Framework

Investigation Objectives

- Analyze HTTP traffic and web server logs.
- Identify suspicious HTTP requests and activities.
- Investigate HTTP methods, including POST requests.
- Identify relevant URLs and request patterns.
- Examine evidence related to the web defacement scenario.
- Document findings and investigation results.

Investigation Approach

The investigation was conducted using Splunk to search and analyze the available security logs.

The process involved:

1. Exploring the available HTTP events.
2. Filtering and analyzing relevant web requests.
3. Investigating suspicious request methods and URIs.
4. Correlating findings to answer the BOTS investigation questions.
5. Documenting the results and supporting evidence.
